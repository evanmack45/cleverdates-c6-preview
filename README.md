# Closer in time (cleverdates.com C6), noindex preview

Three moments; pick the two closest in time; see them to scale. `python3 tools/build_trios.py` validates and writes trios.json (dates, ranges, Wikipedia sources; every answer must hold at both ends of every date range). `node build.mjs` writes docs/ (GitHub Pages).

- Dates: Wikipedia articles linked per event (text CC BY-SA 4.0; we cite and use facts only).
- Fonts: Gloock and Schibsted Grotesk, SIL Open Font License, self-hosted (src/fonts).
- No cookies, storage, analytics, accounts or third-party requests.
